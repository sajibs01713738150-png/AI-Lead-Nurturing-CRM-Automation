# AI-Powered Lead Nurturing & CRM Automation Engine

An production-ready B2B enterprise automation solution built to optimize lead qualification response times, reduce CRM data latency, and execute contextual client follow-ups instantly using Generative AI.

## 🚀 Architectural Overview
The system captures incoming leads via Google Sheets, structures and evaluates the intent using the OpenRouter AI engine, updates the CRM records dynamically, and routes automated email campaigns directly to the prospects based on financial tiers.

## 🛠️ Tech Stack & Microservices
- **Workflow Orchestration:** Make.com (Advanced Scenario Engine)
- **AI Core:** OpenRouter / MiniMax M3.1 Flash LLM (Free Tier Optimization)
- **Agile CRM:** Google Sheets (Relational Row Mapping)
- **Enterprise CRM:** HubSpot Cloud CRM Engine
- **Notification Suite:** Google Workspace Verified Gmail Core Engine

## 📊 Core System Deliverables & Results
1. **Real-time Pipeline:** Enabled zero-latency sync across multi-app ecosystems using batch processing.
2. **Context-Aware Analytics:** Automated 2-line native intent extractions along with programmatic financial tier calculations (\$1000+ threshold verification).
3. **Multi-CRM Synchronization:** Instantly map dynamic leads and inject structured text directly into core HubSpot client entities.
4. **Omnichannel Communication:** Integrated conditional execution loops ensuring instant personalized email routing using Plain text rendering triggers.
